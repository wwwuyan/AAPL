# AAPL

This repository will host the source code for **AAPL**, a framework for text-based person search.

AAPL combines two complementary components:

- **Attribute-Level Alignment (ALA)** aggregates visual and textual tokens into attribute-level representations and aligns them across modalities.
- **Attribute-Aware Prompt Learning (APL)** introduces structured identity and attribute prompts to improve discriminative representation learning.

The framework is evaluated on **CUHK-PEDES**, **ICFG-PEDES**, and **RSTPReID**.
